自动箱形榫 1.2.0 — Windows 安装说明
=====================================

一、安装

1. 完全退出 Autodesk Fusion。
2. 解压发布包，确认得到完整的 BoxJoint 文件夹。
3. 按 Win+R，输入：
   %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns
4. 将整个 BoxJoint 文件夹复制到上述 AddIns 目录。
5. 启动 Fusion。加载项清单已设置为随 Fusion 自动启动。

二、升级

1. 完全退出 Fusion。
2. 备份或删除 AddIns 目录中旧的 BoxJoint 文件夹。
3. 将新版 BoxJoint 文件夹完整复制进去。
4. 不要把新版文件逐个混入旧目录，以免遗留旧脚本或缓存。

三、入口和工具栏

入口位于：设计工作空间 → 实体 → 修改 → 自动箱形榫。
按钮默认不固定。需要常驻时，请在 Fusion 中对该命令执行“固定到工具栏”；
是否固定由当前电脑上的用户自行决定。

四、卸载

完全退出 Fusion，然后删除：
%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\BoxJoint

五、故障排查

如果按钮未出现，请在 Fusion 的“实用程序 → 脚本和加载项 → 加载项”中确认
BoxJoint 已启用，并勾选“启动时运行”。
