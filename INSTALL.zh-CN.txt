自动箱形榫 1.2.0 — Windows 安装说明
=====================================

一、安装

1. 完全退出 Autodesk Fusion。
2. 解压发布包，确认得到完整的 BoxJoint 文件夹。
3. 按 Win+R，输入：
   %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns
4. 将整个 BoxJoint 文件夹复制到上述 AddIns 目录。
5. 确认最终目录中直接存在 BoxJoint.manifest 和 BoxJoint.py，不能多套一层目录：
   AddIns\BoxJoint\BoxJoint.manifest
   AddIns\BoxJoint\BoxJoint.py
6. 启动 Fusion。加载项清单已设置为随 Fusion 自动启动。
7. 如果命令没有出现，打开“实用程序 → 脚本和加载项 → 加载项”，
   找到 BoxJoint，点击“运行”并勾选“启动时运行”。

二、升级

1. 完全退出 Fusion。
2. 备份或删除 AddIns 目录中旧的 BoxJoint 文件夹。
3. 将新版 BoxJoint 文件夹完整复制进去。
4. 不要把新版文件逐个混入旧目录，以免遗留旧脚本或缓存。

三、入口和工具栏

入口位于：设计工作空间 → 实体 → 修改 → 自动箱形榫。
按钮默认不固定。需要常驻时，请在 Fusion 中对该命令执行“固定到工具栏”；
是否固定由当前电脑上的用户自行决定。

四、卸载

完全退出 Fusion，然后删除：
%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\BoxJoint

五、故障排查

如果按钮未出现，请在 Fusion 的“实用程序 → 脚本和加载项 → 加载项”中确认
BoxJoint 已启用，并勾选“启动时运行”。

六、快速使用

1. 准备两个具有真实体积相交的实体；只有贴面接触时不能生成。
2. 打开“设计 → 实体 → 修改 → 自动箱形榫”。
3. 依次选择两个实体，等待半透明相交预览出现。
4. 只在相交预览体上选择一个平面作为榫片配合面。
5. 设置榫片数量和间隙。FDM/PETG 可先用 0.20 mm 间隙试打。
6. 检查红蓝交替预览和状态文本，确认后点击“确定”。
7. 使用“移动/复制”，把移动对象切换为“实体”，移开两个实体检查榫片。

详细参数说明、截图和常见问题请查看 README.md。
